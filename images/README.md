# Images Directory

## animation.gif

Please place your animation GIF file here with the filename `animation.gif`.

The warden login page will use this image as the left-side background. If the file is not found, a CSS gradient animation will be used as a fallback.

**Recommended specifications:**
- Format: GIF (animated)
- Size: Optimized for web (under 2MB recommended)
- Dimensions: 800x600px or larger
- Theme: Waste management, recycling, or environmental themes work well
